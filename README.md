# Semantic Interface Assignment

*Project Folder:* semantic-interface-assignment

## 1. Page Overview
The Semantic Interface Assignment focuses on building a complete semantic HTML page for a Campus Service Desk. The page allows campus users to review open service requests and submit a new request.

The interface includes a site header, primary navigation, a list of existing requests, an accessible request form, response-time information, and a footer with support contact details.

The page uses semantic HTML elements to organize its content according to the purpose of each region. It also uses native HTML form controls and visible labels to make the form easier to understand and use.

The main files included in the project folder are:
- starter.html — contains the HTML page structure and content.
- styles.css — contains the styles used to present the page.
- README.md — provides project information and instructions.
- requirements.md — records the assignment requirements.

## 2. Content Inventory

### 2.1 Purpose and Intended Users
- *Purpose*: Provide a simple interface for viewing open campus service requests and submitting a new request.
- *Intended Users*: Students, staff, and other campus users who need to report a service issue.
- *Primary User Task*: Complete the "Create a request" form and submit the required information.

### 2.2 Main Content Regions
- *Header*: Displays the site name and a short description.
- *Primary Navigation*: Contains links to Dashboard, My Requests, and Help.
- *Main Content*: Houses open service requests and the new request submission form.
- *Footer*: Displays support contact information and copyright.
